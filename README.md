## ✨ Features

* 🔍 Search weather by city name
* 📍 Get weather using current location (Geolocation API)
* 🌡️ Real-time temperature, humidity, wind, pressure, visibility
* 🌅 Sunrise & Sunset timings
* 🌗 Dark / Light theme toggle
* 💾 Saves last searched city (LocalStorage)
* ⚡ Skeleton loading animation
* 🎯 Accurate weather using latitude & longitude (Geo API)
* 🎨 Clean and modern UI design

## ⚙️ How It Works

1. User enters a city name
2. App converts city → coordinates (Geo API)
3. Coordinates → fetch weather data
4. Data is displayed dynamically on UI

---

## 🔑 Setup Instructions

1. Get a free API key from OpenWeatherMap
2. Open `script.js`
3. Replace:

```javascript
const API_KEY = "YOUR_API_KEY_HERE";
```

4. Run the project by opening `index.html`
